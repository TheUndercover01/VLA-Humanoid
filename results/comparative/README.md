# Comparative study archive (7 Oct 2026)

Everything needed to compare the students and the teachers of this project later. Small files are in this folder (in the repo); the large
artifacts (models, videos, datasets, teacher checkpoints) are in `/media/storage/ayush/archive_comparative_7oct/` (`ARCHIVE_COMPLETE` appears when the copy is done).

| file / folder | what it holds |
|---|---|

| `students.csv` | one row per student: environment, teacher, episodes, how the prompt is given, progress signal (done flag / memory), VLA setup, early stop, final loss, notes |

## How to read the numbers
* **Lenient** (the user's choice for headline numbers): the last command's outcome was reached and held for 0.5 s. Strict success is only in the older rows of `evals_long.csv`.
* **In order**: every command's outcome held for 0.5 s in turn (the lenient check alone credits runs that skipped steps).
* Evaluation: 100 fixed validation layouts per chain (seed 4321), the same for every model of the same environment.
* **Three environments**: red/blue cubes with a random target (groups A and B of `COMPARISON.md`), and a cube + cylinder with a fixed target (group C). Do not compare numbers across them.
* **Three ways of giving the instruction** (the point of the study): (1) the whole sentence once, no progress signal; (2) one command at a time, the environment's own done check moves on (an oracle, not a policy), or the VLA's own done flag moves a pointer held by the harness; (3) the whole sentence once plus the policy's own done count as memory (`ours_cyl_memory`).
* Evaluation settings that changed during the week: the done-flag threshold / ticks (0.5 / 3 at first, 0.7 / 5, 0.85 / 8, then 0.85 / 5 as the default), and the in-order metric (added 6 Oct 15:00).

## Reproduce
`PROGRESS.md` (repo root) is the running log with the cause of every result. The pipelines are `scripts/distill_*.sh`; the real-clip chain is `handtrack/cut_session.py` -> `track_objects.py` / `calibrate_session.py` -> `make_clips.py` -> `motion/keypoint_ref.py --straight` -> `sim/train_rl.py` (with `VLA_OBJECTS=cube_cylinder VLA_FIXED_TARGET=0.03,-0.12 VLA_PUSH_C3=0.5`) -> `scripts/distill_cyl_fixed.sh` or `scripts/distill_memory.sh`.
